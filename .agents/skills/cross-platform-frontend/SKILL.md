# Cross-Platform Frontend Implementation Skill

Use this skill when implementing UI screens, controllers, camera/file scanning integrations, or QR customization interfaces.

## Mandatory Standards

1. **Multi-Platform Hardware & File Input**:
   - Support live camera capture on mobile/desktop where hardware is present AND direct image/screenshot/file decoding (`.png`, `.jpg`, `.webp`, `.bmp`, clipboard) across all 5 OS targets (Android, iOS, Windows, Linux, macOS).
2. **Zero Dead Controls**:
   - Every button, filter chip, search bar, slider, color picker, export action, and context menu must execute real domain logic and update application state.
3. **Validation**:
   - Run `flutter analyze` and `flutter test` in the modified package or application before marking work complete.
