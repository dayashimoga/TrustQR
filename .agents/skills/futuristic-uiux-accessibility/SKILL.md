# Futuristic UI/UX, Responsive Layout & Accessibility Skill

Use this skill when building or auditing widgets in `packages/qr_design_system`, `apps/user_app`, and `apps/admin_app`.

## Design & Ergonomic Standards

1. **Cyber-Precision Aesthetic**:
   - High-contrast obsidian/slate dark theme & crisp alabaster light theme, neon cyan/emerald/amber semantic accents, translucent glassmorphic cards, and smooth laser-HUD scanner reticle animations.
2. **Adaptive Form-Factor Breakpoints**:
   - **Compact (`< 600px`, Mobile)**: Bottom navigation bar, thumb-friendly action dock, full-bleed scanner viewport.
   - **Medium (`600px – 1024px`, Tablet / Foldable)**: Navigation rail + two-pane master-detail split view.
   - **Expanded (`> 1024px`, Laptop / Desktop)**: Full navigation sidebar, multi-pane workspace (live preview + inspector + history/analytics), and keyboard shortcuts (`Ctrl/Cmd+O`, `Ctrl/Cmd+G`, `Ctrl/Cmd+F`, `Ctrl/Cmd+S`).
3. **Accessibility & Localization**:
   - Semantic labels on all icon buttons and scanner/generator canvases, dynamic text scaling support, and localized strings via standard localization delegates.
