# Universal QR Code Scanner & Generator Platform

A high-performance, zero-trust, cross-platform **QR Code Scanner and Generator Ecosystem** built with **Flutter & Dart** for **Android, iOS, Windows, Linux, and macOS** across mobile, tablet, laptop, and desktop form factors.

---

## Two Physically & Cryptographically Separated Applications

| Capability | **Admin App (`apps/admin_app`) — Premium** | **User App (`apps/user_app`) — Restricted** |
| :--- | :---: | :---: |
| Live Camera, Image, Screenshot & File QR Scanning | Yes | Yes |
| Multi-QR Batch Matrix Vision (Single Image / Frame) | Yes | Yes |
| 15+ Structured Payload Parsers (URL, Wi-Fi, vCard, UPI, TOTP, etc.) | Yes | Yes |
| Zero-Trust Anti-Phishing & Threat Firewall (0–100 Safety Score) | Yes | Yes |
| `TrustQR` Ed25519 Cryptographic Signature Verification | Yes | Yes |
| Offline-First Vault (History, Favorites, Collections, Tags, Search) | Yes | Yes |
| **QR Code Generation & Artistic Customization (Shapes, Gradients, Logos)** | **Yes (Admin Only)** | **Physically Excluded & RBAC Blocked** |
| **Real-Time Scannability & Contrast Simulator** | **Yes (Admin Only)** | **Physically Excluded & RBAC Blocked** |
| **High-DPI PNG, Vector SVG, Print PDF & Batch CSV/JSON Generation** | **Yes (Admin Only)** | **Physically Excluded & RBAC Blocked** |
| **`TrustQR` Ed25519 Cryptographic Payload Signing** | **Yes (Admin Only)** | **Physically Excluded & RBAC Blocked** |
| **Admin Analytics Dashboard, Fleet Registry & Audit Reports** | **Yes (Admin Only)** | **Physically Excluded & RBAC Blocked** |
